# Погода UMEDJON

Официальный канал бесплатных обновлений приложения `com.umedjon.weather`.

Новые версии сначала подготавливаются как Draft Release. Владелец проверяет APK и самостоятельно публикует выпуск. После публикации GitHub Actions проверяет APK и метаданные и обновляет `updates/stable.json`.

Первую версию с этим механизмом обновлений необходимо установить вручную поверх прежней версии. Следующие опубликованные совместимые версии приложение сможет предлагать при открытии.

Сценарии подготовки и проверки находятся в `update-tools/release_tools.py`, workflow — в `.github/workflows`. Стабильный канал использует только проверенные опубликованные выпуски. Закрытый ключ Android-подписи и постоянные токены хранятся отдельно от репозитория.
